### Comment tout retirer d'un coup

Dans `index.html`, décommenter les deux lignes signalées dans le bloc
« VISUELS PROVISOIRES » du CSS :

```css
[data-provisoire] img { display: none !important; }
.wip-equipe-vignettes button i { display: block !important; }
.wip-espace-note b, .wip-coach-note b { display: none !important; }
```

Les quatre filigranes de la section 01 et les trois portraits de la section 05
disparaissent. **Les briefs de prise de vue restent affichés** — ce sont des outils de
production, pas des visuels —, les vignettes de l'équipe reprennent leurs initiales, et
le badge bleu « Visuel provisoire » s'efface avec ce qu'il signalait. Aucune autre
modification n'est nécessaire.

*(Le sélecteur a été élargi de `.wip-photo[data-provisoire]` à `[data-provisoire]` le
26/08/2026 : ni les vignettes de l'équipe ni les fonds d'espace ne sont des
`.wip-photo`.)*

**Puis supprimer la ligne `Disallow: /media/provisoire-` de `robots.txt`.** Elle a été ajoutée
le 27/08/2026 comme filet de sécurité : si le site part en ligne avant le shooting, elle évite
au moins que ces images soient indexées dans Google Images sous le nom de la salle. Elle
n'empêche pas leur affichage sur la page — seul le CSS ci-dessus le fait.

Redimensionnées à 1200 px de large, désaturées à 55 % et réencodées en JPEG qualité 80
pour les rapprocher de la charte photo (§5 ter : désaturation, grain conservé) et les
homogénéiser entre elles.

### `wip-hero.mp4` — 14,4 Mo *(réencodée le 25/08/2026)*

**Corrigé le 28/08/2026** : cette fiche annonçait encore 75,8 Mo, chiffre relevé avant le
réencodage. Le fichier pèse aujourd'hui **14,4 Mo**, soit cinq fois moins.

Le script ne pose le `src` que sur grand écran : un téléphone ne télécharge rien. Reste que
14 Mo sur une page qui devrait en peser deux, c'est le poste le plus lourd du site et un frein
mesurable aux Core Web Vitals — donc au classement. Cible si on veut aller au bout : boucle de
8 à 12 s, 1920 × 1080, sans piste audio, ~2 Mo. Ce n'est plus urgent, c'est une optimisation.

Exclue du crawl par `robots.txt` : aucun moteur n'a de raison de la télécharger.
